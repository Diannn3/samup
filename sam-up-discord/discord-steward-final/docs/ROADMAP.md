# Post-1.0 roadmap

The core one-server setup, moderation, dashboard, MCP, audit, rollback, AutoMod, and enforcement paths are present. Future work is optional hardening rather than a prerequisite to ingesting the repository into Antigravity.

## Recommended enhancements

- Staging-guild end-to-end fixtures and recorded Discord API simulations
- Durable external work queue if moderation volume grows beyond one student server
- Malware reputation provider integration for attachment hashes
- OCR and sampled-frame video moderation with explicit privacy controls
- Formal appeals workflow with a member-facing form
- Backup encryption and scheduled restore drills
- Metrics export and false-positive calibration reports
- Native installers for Windows and Linux service managers
