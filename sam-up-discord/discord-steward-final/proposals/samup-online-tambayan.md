# SAM-UP Online Tambayan Architecture Proposal

## Core Philosophy
We are shifting the server from an administrative bureaucracy heavily focused on structural management, to a **sustainable online tambayan** for members to relax, connect, and collaborate.

## Key Changes
1. **Flatter Hierarchy**: Removed excessive duplicate channels (like `gen-chat` and `gen-chat-2`).
2. **Reduced Voice Clutter**: Consolidated numerous empty voice rooms (`acad nights`, `lobby`, multiple `sports night`) into focused `Tambayan`, `Study Room`, `Gaming Room`, and `Music Room`.
3. **Forum Introduction**: Introduced Forum channels for `#academic-help`, `#opportunities`, and `#resources` to prevent chat clutter and make discussions searchable.
4. **Protected Onboarding**: Maintained the existing verification infrastructure in the newly named `START HERE` category to avoid disrupting current flows.
5. **No Committee Channels**: Eliminated the need to create 5+ committee-specific channels. Committee work happens elsewhere; this server is for member interaction.
6. **Student-Friendly Content**: Prepared new, non-corporate welcome text, guidelines, and bylaws summaries tailored to UPLB students.
