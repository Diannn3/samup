# Onboarding Options

Based on the existing server audit, there is a fully functional verification workflow driven by the `Ticket Tool` bot (ID: 557628352828014614) in the `BULLETIN BOARD` category via the `verification` channel and ticket threads.

## Recommended Option: OPTION A — EXISTING VERIFICATION FIRST
- **Why:** The existing verification system is deeply integrated and active. Transitioning to Native Discord Onboarding might disrupt the current application processes and break existing tickets.
- **Workflow:** 
  1. User joins.
  2. User can only see the `START HERE` category containing `welcome-to-sam-up`, `constitution-and-bylaws`, `server-guidelines`, `important-links`, and `verification`.
  3. User reads guidelines and opens a ticket in `verification`.
  4. Moderation/Membership team verifies the user and assigns the `Verified` role.
  5. The `Verified` role unlocks the rest of the server (`OFFICIAL`, `TAMBAYAN`, `ACADEMICS`, `INTERESTS`, `VOICE TAMBAYAN`).
